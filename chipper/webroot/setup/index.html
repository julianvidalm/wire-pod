Vector setup needs Google Chrome (or another Chromium browser) with Web Bluetooth.

Pair with Vector

Chrome lists the robots it finds; pick yours.

  1. Place Vector on his charger.
  2. Double-press Vector's button, then click Pair with Vector.
  1. Wait until Vector finishes restarting, then click Pair with Vector. If he doesn't connect, double-press his button.

Update the firmware

Vector is in recovery mode and needs firmware before setup can go on. He downloads it from this server over Wi-Fi.

Choose the firmware to install.

No firmware (.ota) files on this wire-pod server. Copy one into <data dir>/robot/ota (by default ~/.local/share/v3ctor/robot/ota) and pair again.
